# Mutlu Göbekler 🍔🥤

A food and beverage ordering app developed using **Flutter** and **Dart**. With a focus on user experience, this app allows users to browse, customize, and order meals and drinks with ease.

## Features 🌟

- **User Authentication**: Secure login and registration using Firebase authentication.
- **Comprehensive Food & Drink List**: Browse through a variety of meals and beverages with detailed information about each item.
- **Cart Management**: Add items to your cart, customize your orders, and seamlessly manage your cart before placing an order.
- **Intuitive Ordering**: User-friendly interface ensures a smooth experience for exploring, selecting, and ordering your favorite items.
- **Firebase Integration**: Manages user accounts and authentication through Firebase, ensuring secure and real-time data handling.

## Technologies Used 💻

- **Flutter & Dart**: For building a fast and responsive cross-platform app.
- **Firebase**: Used for user authentication and backend data management.
- **Provider**: To manage the state of the cart and order processes efficiently.
- **Firestore**: Storing and retrieving the food and beverage data.
